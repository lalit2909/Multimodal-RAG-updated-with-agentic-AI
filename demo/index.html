🧠 Enhanced Multimodal RAG Agent

Multimodal ingestion (PDF · Image · Audio · Video) + Agentic decision layer (Local KB ↔ Web Search) + Source-attributed answers

How the agent works

The agent doesn't blindly answer. It retrieves, evaluates, and only falls back to the web when local context is insufficient.

1. QueryUser submits a question.
2. Local retrievalTop-5 chunks from ChromaDB (sim ≥ 0.30).
3. EvaluateGemini judges if context is sufficient.
4a. Sufficient?If yes → answer from local KB only.
4b. FallbackIf no → DuckDuckGo search + fetch.
5. Final answerLabeled Local / Web / Both.
🟢 Local Knowledge Base

Answered entirely from your uploaded PDFs / images / audio / video.

🔵 Internet Sources

Local KB didn't have it; fell back to DuckDuckGo web results.

🟣 Both

Final answer drew materially on local + web context.
